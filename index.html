    Built for the super{set} hackathon, Public Data APIs track. Sources: Grants.gov, USAspending.gov, IRS Form 6765 guidance, KPMG/Aprio/CLA state credit summaries.

    Data & limits

    • Grants.gov Search API: live open and forecasted opportunities, keyword-matched to verticals (imperfect matching). Grants.gov does not allow direct browser calls (CORS), so the hosted demo shows a dated snapshot pulled from the live API; the badge says which you are seeing.
    • USAspending.gov API: FY2024-25 award dollars whose records mention SBIR/STTR, by state of performance. A keyword proxy, not an official SBIR total.
    • State credit table: hand-compiled headline rates (no public API exists). 20 states only; rules change annually. Verify before filing.
    • Fallback: if an API is blocked or down, the app shows a dated cached snapshot and labels it.
    • Privacy: calculator inputs never leave your browser. No accounts, cookies, or analytics.
    • Not tax advice. The estimator simplifies eligibility, base periods, and state apportionment, and the 2025 federal changes to R&D expensing should be confirmed with a CPA.
